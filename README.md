### Tools Used
Power BI | DAX | Power Query | Excel

### Project Objective
To analyze workforce data, identify attrition patterns, evaluate employee engagement, and support HR workforce planning through interactive dashboards.

*Note: The risk model is rule-based and intended for HR review and decision support, not automated employment decisions.*
